# Call quality, accuracy and reliability fixes (2026-09-30)

Test suite: **773 passed** (before: 13 failing). No new lint issues.

## 1. Voice noise / static

| Problem | Cause (confirmed in logs/code) | Fix |
|---|---|---|
| Loud static on some calls | When ElevenLabs failed (12× HTTP 502 on 29 Sep), the OpenAI fallback returned **MP3**, which was streamed to Exotel as if it were raw audio. | Fallback now requests raw PCM (`response_format="pcm"`) and converts it to 8 kHz. Every outbound chunk is also checked, and any non-PCM data is dropped instead of played. (`app/voice/openai_provider.py`, `app/voice/pcm.py`) |
| Hiss / metallic "sss" on every AI sentence | 16 kHz → 8 kHz conversion dropped every other sample with no low-pass filter, so 4–8 kHz sibilance folded back into the audible band (aliasing). | Anti-aliasing low-pass filter before decimation, streaming-safe across chunks. Measured: speech band unchanged, **47 dB less** aliased hiss. (`app/voice/pcm.py`, `app/voice/elevenlabs.py`) |
| Clicks between sentences | Each sentence is a separate TTS request that could start or stop on a non-zero sample. | 8 ms fade at the edges of each sentence. |
| AI goes permanently silent mid-call | The outbound writer used `assert`: one odd-length or bad chunk killed the writer task for the rest of the call. | Bad chunks are trimmed or dropped and the writer keeps running. |
| Bot answers background noise, gets "interrupted" by noise | Fixed energy threshold: on noisy lines (traffic, fan, crowd) the noise itself counted as speech. | Adaptive noise gate: speech must be 3× the line's measured noise floor (low-percentile estimate, so talking doesn't raise it). Quiet lines are exactly as sensitive as before. (`app/voice/vad.py`, `NOISE_FLOOR_MULTIPLIER`) |
| Bot replies to things nobody said ("Thank you for watching") | Speech-to-text hallucinates stock phrases on noise. | Hallucination filter (`app/voice/transcript_filter.py`), better STT model, `temperature=0`. |
| Bot hears its own voice | `_finish_playback` could return while the final frames were still queued, switching to "listening" while the AI was still talking. | Waits for the queue to drain before listening. |

## 2. Accuracy

- **STT model**: `gpt-4o-transcribe` (configurable via `STT_MODEL`), with automatic fallback to `whisper-1`. A vocabulary prompt (company name, services) makes it recognise "Kinikh", "renovation" and similar terms correctly.
- **New receptionist prompt** (`app/prompts/system.py`): written for voice (short spoken sentences, one question at a time, no lists or symbols), answers strictly from company data (never invents prices or dates), handles speech-to-text mistakes, collects name, requirement and callback number naturally, confirms in one sentence, then closes the call.
- **Caller context in the prompt**: the last 4 digits of the caller ID (so the AI can confirm the callback number) and the current date/time in India.
- **Lead extraction prompt**: uses only what the caller said or confirmed, converts spoken emails ("rahul dot sharma at gmail dot com"), picks a department from the configured list, and writes everything in English.
- **Department routing**: the extracted department is normalised to a configured name (or classified). Before, free text like "Interior design" never matched, so every lead email went to the fallback address.
- **History**: knowledge snippets are no longer appended as `[SYSTEM]` lines every turn (they duplicated the system prompt and polluted the saved transcript). A sentence counts as "spoken" only once its audio has actually been sent, so after an interruption the AI no longer thinks the caller heard sentences that never played.

## 3. Conversation flow

- **Language detection was never running.** Every call stayed "en", so Hindi callers got the English voice and English fallback phrases. It now runs on every caller turn, offline (no API call, no added latency), and one-word replies like "ok" never flip a Hindi call back to English.
- **Ending the call**: the AI ends with a hidden `[END_CALL]` marker. It is never spoken; after the goodbye plays, the stream closes and Exotel moves to the next applet (add a Hangup applet). The old farewell/confirmation code could never run.
- **Silence**: after 8 s of caller silence the AI asks "Are you still there?". After 2 unanswered prompts it says goodbye and ends the call. If the caller speaks during the goodbye, the call continues.
- **Just-in-time TTS**: the next sentence is synthesized shortly before it's needed, so interrupted replies don't waste ElevenLabs characters.

### Follow-up after the first live call (13:36)

- **Greeting was cancelled by the caller's "hello"** at pickup, before it became audible, so the caller heard silence. The greeting can no longer be cancelled that way.
- **Repeated "hello?" starved every reply**: each new utterance cancelled the pending reply and merged it into a longer turn, so the AI never spoke. A pending reply is now merged away at most once (`MAX_RESUME_MERGES=1`), then kept.
- **Greeting plays instantly**: it is synthesized once at startup and cached, instead of waiting about 1.2 s for TTS on every call.

## 4. Other bugs fixed

- **Email**: port 465 (SSL) sends failed with "Connection unexpectedly closed" (seen in logs). Sending now uses SMTP_SSL for 465, like the connection test already did, with a 30 s timeout.
- **Startup**: `STREAM_TOKEN_SECRET` was required but unused and missing from `.env.example`, so the app wouldn't start without it. It's now optional.
- **STT retries**: an empty transcript (silence) is no longer retried, which removes a second paid call and ~0.5 s of dead air per noise burst. The retry also re-sent an already-consumed file object; each attempt now gets a fresh one.
- **Classifier**: returns the configured spelling of department names (DB lookup is exact-match).
- **Demo-data warning** is no longer in the live prompt (the AI could read it to callers); it is logged instead.
- `scripts/dev.sh` now passes `--proxy-headers`.

## New / changed settings (`.env`)

```
STT_MODEL=gpt-4o-transcribe
STT_FALLBACK_MODEL=whisper-1
NOISE_FLOOR_MULTIPLIER=3.0      # raise to 4 for very noisy callers, 0 = off
NOISE_GATE_MAX_RMS=2000
SILENCE_REPROMPT_SECONDS=8      # 0 = off
MAX_SILENCE_REPROMPTS=2
PUBLIC_BASE_URL=https://ivr.yourdomain.com
```

New dependency: `numpy` (run `pip install -r requirements.txt`).
